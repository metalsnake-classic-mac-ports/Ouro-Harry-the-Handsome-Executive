# The sprite record (0xa2 bytes, SATSetSpriteRecSize(0xa2) in InitSAT).
# 0x00-0x4d follow SAT's Sprite record; the rest is Harry's own.
# offset type name comment
0x00 short kind          SAT: kind (> 0 friend, < 0 foe)
0x02 short posV          SAT: position.v (pixels)
0x04 short posH          SAT: position.h
0x06 Rect  hotRect       SAT: collision rect, relative to position
0x0e Rect  hotRect2      SAT
0x16 ptr   face          SAT: face to draw
0x1a ptr   task          SAT: per-frame routine (TVector)
0x1e ptr   hitTask       SAT: collision routine (TVector)
0x22 ptr   destructTask  SAT
0x26 ptr   clip          SAT
0x4c short layer         SAT: drawing order (player 10)
0x4e short speedV        1/256 pixel per frame
0x50 short speedH
0x52 short scale0        0x100 = 1.0
0x54 short scale1
0x56 short scale2
0x58 short scale3
0x5a short atV           working copy of posV (top-left), moved by the collision code
0x5c short atH           working copy of posH
0x5e int   fixH          position.h << 8
0x62 int   fixV          position.v << 8
0x66 short dir           direction 0..35 (10 degree steps), ApplyModedImpulse mode
0x68 short levelIndex    index in the level's sprite list, -1 none
0x72 short state
0x74 short timer
0x76 short idleIndex     slot in the idle sprite table (set by IdleToActiveSprite)
0x7e ptr   faceEntry     current face (face set + frame * 0x1c)
0x8e short air           jump / fall state: 1-35 jump, 215-220 half-pipe flip, 1000-1045 falling into a hole; >= 23 cannot move
0x92 char  frozen        task does nothing while set
0x96 short blastCooldown frames until an explosion hurts again (30, HandleExplodeRadius)
0x98 short lastTileH     tile column of the last HandleHalfPipe
0x9a short lastTileV     tile row
0x9c short slide         background kind under the sprite at the last HandleHalfPipe
0x90 short flipKind      half-pipe flip: 0x26ad down, 0x26ae up, 0x26af right, 0x26b0 left
0x9e ptr   hitTileTask   collision with tiles (TVector), e.g. HitPlayerTileSprite
